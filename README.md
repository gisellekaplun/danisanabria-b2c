# Dani Sanabria — Mentoría Laboral (Versión 3)

Landing page para Dani Sanabria, mentora laboral especializada en mentoría individual para jóvenes profesionales.

## Estructura

- `index.html` — Página principal (hero, servicios, metodología, planes, testimonios, formulario de contacto).
- `preguntas-frecuentes.html` — Preguntas frecuentes.
- `vercel.json` — Configuración de despliegue en Vercel.

## Despliegue

Subido a [Vercel](https://vercel.com).
